### Как я выполнил каждый файл
#### Krygok
   Использовал формулу площади круга которую вывели задолго до нас. Число пи я вставил из библиотеки math
> n * r * r
   Пример: если r = 3, то площадь будет равна примерно 28,27433388230813914616379044952
#### Priamoygolnik
   Площадь прямоугольника выражается произведением двух не противоположных сторон
> a * b
   Пример: a = 3, b = 7, площадь равна 21
#### Triangle
   Я использовал сторону и высоту для вычисления площади треугольника
> a * h / 2
   Пример: сторона а = 4, h = 3, а площадь равна 6
#### Kvadrat 
   Квадрат это частный случай прямоугольника. Но я решил выделить этот случай
> a * a
   Пример: сторона квадрата а = 4, площадь равна 16
